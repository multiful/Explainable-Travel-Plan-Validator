# Step 2. 설명 생성 오케스트레이션

## 역할

`src/explain/explain_engine.py`는 검증 결과를 근거 기반 설명으로 변환한다. Hard Fail, Warning, 점수, 패널티·보너스, 일정 모델을 입력으로 받고 `ExplanationItem` 목록을 반환한다.

설명 생성에 필요한 외부 호출은 Explain 레이어가 담당하는 Anthropic 클라이언트에서만 수행한다. 문서 파싱도 같은 원칙으로 처리하며, 키가 없거나 호출이 실패하면 규칙 기반 설명으로 안전하게 폴백한다.

## 근거 조회

`src/data/evidence_retriever.py`의 `LocalEvidenceRetriever`가 `data/jeju_places.csv`를 읽어 지역 정보와 인근 대안을 제공한다. 이 카탈로그는 설명의 근거를 보강하지만 검증 계산을 임의로 바꾸지 않는다.

라이브 점검은 다음 명령으로 실행한다.

```bash
python scripts/demo_live_e2e.py
```

실제 Anthropic 키가 없는 환경에서는 라이브 점검을 실행하지 말고 mock 기반 테스트를 사용한다.

## 품질 규칙

- 외부 응답을 설명의 사실처럼 만들지 않고, 입력된 검증 근거와 데이터 신뢰도를 함께 전달한다.
- 호출 실패는 전체 검증 실패가 아니라 안전한 폴백으로 처리한다.
- 모든 외부 클라이언트는 테스트에서 mock/stub으로 대체한다.
- 설명 생성기는 API 라우터에 직접 배치하지 않는다.

그래프 데이터베이스 의존성은 ADR-005에 따라 제거되었다. 과거 구현을 새 런타임에 다시 연결하지 않는다.
